# U-16プログラミングコンテスト釧路大会 実行委員会 会則

## 第1章 総則

**第1条（名称）** 本会は、U-16プログラミングコンテスト釧路大会実行委員会（以下「本会」という。）と称する。

**第2条（事務）** 本会は事務局を置かず、本会の事務は委員長が総括し、役員が分担して処理する。

**第3条（目的）** 本会は、16歳以下の児童・生徒を対象としたプログラミングコンテスト及び講習会を開催し、釧路地域の子どもたちにプログラミングの楽しさを伝えるとともに、論理的思考力及び創造力の育成並びに情報技術分野の人材育成に寄与することを目的とする。

**第4条（事業）** 本会は、前条の目的を達成するため、次の事業を行う。

1. U-16プログラミングコンテスト釧路大会（以下「大会」という。）の企画及び運営
2. プログラミング未経験者を対象とした講習会の企画及び運営
3. 大会及び講習会に関する広報活動
4. 上位大会への参加に関する支援
5. その他本会の目的を達成するために必要な事業

## 第2章 委員

**第5条（組織）** 本会は、本会の目的に賛同する者（以下「委員」という。）をもって組織する。

**第6条（入会）** 委員になろうとする者は、委員長に申し出て、その承認を得なければならない。

**第7条（退会）** 委員は、委員長に届け出ることにより、いつでも退会することができる。

**第8条（除名）** 委員が本会の名誉を著しく傷つけ、又は本会の目的に反する行為をしたときは、総会の議決を経て除名することができる。この場合、当該委員に弁明の機会を与えなければならない。

## 第3章 役員

**第9条（役員）** 本会に、次の役員を置く。

1. 委員長　1名
2. 副委員長　若干名
3. 会計　1名

**第10条（選任）**

1. 委員長、副委員長及び会計は、委員の中から総会において選任する。

**第11条（職務）**

1. 委員長は、本会を代表し、会務を総理する。
2. 副委員長は、委員長を補佐し、委員長に事故があるとき又は委員長が欠けたときは、その職務を代理する。
3. 会計は、本会の会計事務を処理する。

**第12条（任期）**

1. 役員の任期は1年とし、再任を妨げない。
2. 補欠により選任された役員の任期は、前任者の残任期間とする。
3. 役員は、任期満了後も後任者が就任するまでの間、その職務を行う。
4. 役員が任期中に委員でなくなったときは、その役職を退くものとする。

## 第4章 会議

**第13条（会議の種類）** 本会の会議は、総会とする。

**第14条（総会）**

1. 総会は委員をもって構成し、毎年度1回以上、委員長が招集する。
2. 委員の3分の1以上から会議の目的を示して請求があったときは、委員長は臨時総会を招集しなければならない。
3. 総会は、次の事項を審議し、議決する。
   1. 事業計画及び予算
   2. 事業報告及び決算
   3. 役員の選任
   4. 会則の変更
   5. その他本会の運営に関する重要事項
4. 総会の議長は、委員長が務める。

**第15条（定足数及び議決）**

1. 会議は、委員の過半数の出席がなければ開くことができない。
2. 会議の議事は、この会則に別段の定めがある場合を除き、出席者の過半数で決し、可否同数のときは議長の決するところによる。
3. やむを得ない理由により出席できない委員は、書面又は電磁的方法により議決権を行使し、又は他の委員に委任することができる。この場合、出席したものとみなす。

**第16条（開催方法）**

1. 会議は、対面のほか、オンライン会議システム又は電子メール等による書面審議の方法により開催することができる。
2. 書面審議においては、委員長が定める期間内に賛否を表明した委員を出席したものとみなす。
3. 前項の賛否の表明の方法は、委員長が別に定める。

**第17条（議事録）** 会議の議事については、議事録を作成し、委員が閲覧できるよう保管しなければならない。

## 第5章 会計

**第18条（経費）** 本会の経費は、協賛金、補助金、助成金、寄付金及びその他の収入をもって充てる。

**第19条（会計年度）** 本会の会計年度は、毎年4月1日に始まり、翌年3月31日に終わる。

**第20条（予算及び決算）**

1. 本会の事業計画及び予算は、委員長が作成し、総会の議決を経なければならない。
2. 本会の事業報告及び決算は、会計年度終了後、総会において役員以外の委員が確認したうえで、その承認を得なければならない。
3. 総会の承認を得るまでの間に必要な支出は、委員長の判断により執行することができる。この場合、次の総会で報告しなければならない。

**第21条（会計の管理）**

1. 本会の金銭は、本会名義の口座等により、委員個人の財産と区別して管理する。
2. 会計は、すべての収入及び支出について、帳簿及び領収書等の証拠書類を整備し、保管しなければならない。

## 第6章 雑則

**第22条（個人情報の取扱い）**

1. 本会は、大会及び講習会の参加者並びにその保護者の個人情報を、事業の運営に必要な範囲でのみ取得し、利用する。
2. 参加者の氏名、写真、作品等を広報等に使用する場合は、あらかじめ保護者の同意を得なければならない。
3. 取得した個人情報は適切に管理し、利用目的を達成した後は速やかに廃棄する。

**第23条（参加者の安全確保）** 本会は、大会及び講習会の実施にあたり、参加者の安全の確保に努めなければならない。

**第24条（会則の変更）** この会則は、総会において出席者の3分の2以上の賛成により変更することができる。

**第25条（解散）**

1. 本会は、総会において出席者の3分の2以上の賛成により解散することができる。
2. 解散時に残余財産がある場合は、総会の議決により、本会と類似の目的を有する団体に寄付するものとする。

**第26条（委任）** この会則に定めるもののほか、大会の競技規程その他本会の運営に必要な事項は、委員長が別に定め、総会に報告するものとする。
